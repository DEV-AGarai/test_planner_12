📘 JEE Test Planner – Physics Wallah
Welcome to the official repository for the JEE Test Planner — a centralized platform for managing and viewing test schedules for various Physics Wallah (PW) batches including:
- 🧪 Lakshya JEE 2026
- ⚡ Lakshya JEE Power Group 2026
- 🚀 JEE Ultimate Crash Course 2026
This site helps students stay organized, track upcoming tests, and prepare efficiently for JEE Main and Advanced.

🔍 Features
- 📅 Full test calendar with batch-wise breakdown
- 🧠 Subject-wise syllabus for each test (Physics, Chemistry, Maths)
- 🧪 Test type and pattern (Part Test, Full Test, Board Pattern, etc.)
- 📱 Mobile-friendly and responsive design
- 🔎 Search and filter by date, batch, or topic
- 🧭 Admin dashboard for managing test data (optional)

🚀 Getting Started
To run the project locally:
git clone https://github.com/your-username/test-planner.git
cd test-planner


Set up your environment:
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt


Run the server:
python manage.py runserver



🗂️ Data Management
Test data is stored in the TestSchedule model. You can populate it using:
- Django shell scripts (see scripts/)
- Management commands
- CSV import functionality (coming soon)
